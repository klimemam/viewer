## 3. σ_fpn の補正 (判断2) は閉じているか — **閉じている**

**式の照合** (`temporal_model.inc` 対 仕様 (b)): 画素毎 n_i / NaN 画素毎除外、
s_t,i² は ddof = n_i−1 (クランプ→スケールの順序まで serve.cpp と bit 比較可)、
C = mean_i(s_t,i²/n_i) を**画素ごとの n_i** で、var_spatial(M) は ddof=1、
`σ_fpn² = max(0, var_spatial(M) − C)`、`fpnCorr = √C` を値の隣に、クランプは
`fpnClamped` → 琥珀の「0 (clamped)」+ 脚注 + TSV の clamped 列。未補正上界は
`sqrt(sigma_fpn² + fpn_corr²)` で復元できる (#127 の流儀)。**全項一致。**

**ddof 統一後の前提。** 問いの前提に 1 点訂正が要る: 2026-08-10/11 の裁定は
「全経路 ddof=1」では**ない** — I 群 (記述統計) = 0、II 群 (行/列平均のσ) = 1、
III 群 (推定量の入力) / IV 群 (時間σ) = 従前どおり 1 / n_i−1、である。
判断2 の式が立つのは III・IV 群の上で、裁定はそこを**動かしていない**
(taxonomy §6.2 が対象外と明記)。恒等 `E[S²_ddof1(M)] = σ_fpn² + C` は
成立し続け、引き算の不偏性も変わらない。むしろ判断8 の適用範囲段落が
「(a) の一行を読んで ROIs を『直す』」事故 — 補正の前提を S1 に広げる逆流 —
を防いでいる。**前提は変わっていない。壊れる方向の変更は入っていない。**

**記録する留保 (決めない)**: temporal_model の標本は間引き (40k 上限) +
CFA セル単位で i.i.d. ではない。I 群を ddof=0 にした理由と同じ事情が III 群の
入力にもあるが、ここでの ddof=1 の理由は不偏性の約束ではなく**引き算の恒等**
なので矛盾しない。再訪条件: 相関標本による C の偏りが実測で見えたら。

**クランプ規則との関係。** PR #184 (splitValid) は第 3 の状態を作った:
「測って 0 (clamped)」と「測っていない (−)」。方向は正しい — clamped の文は
「この stack の時間床より上に固定パターンが分解できない」という**測定**であり、
一画素にはその測定が**無い**。規則「クランプを黙らせない」は強められており
弱められていない。ただし仕様 (b) は 2 状態しか書いていない → 書き戻し (§6-1)。

## 4. 平坦性の指標 — 同じものを2通りで言っていないか

**実物は 2 つではなく 4 つの顔**を持つ:

| | 量 | 出る場所 | 性格 |
|---|---|---|---|
| (i) | σ_col / σ_row (行/列平均のσ、% 併記、ddof=1) | Projection 表 / Temporal export | 縞の **RMS**。(a) 着地後は推定量の部品 A/B |
| (ii) | p-p row / col / frame [DN] | Projection 表 | プロファイル全域の**極値幅** |
| (iii) | **見えている範囲の p-p** (% of mean) | Projection / Temporal のプロット下 (PR #190) | (ii) を可視窓に制限して mean で割ったもの。窓に依存 |
| (iv) | shading [%] / shading p-p [DN] (2次面 probe) | Set Analysis 常設 / detrend note | **低周波面の振幅** — 約束4 の「測りたい量」 |

**判定: 同じものを 2 通りではない** — σ は RMS、p-p は極値、shading は
低周波面で、推定量として別物。ただし (iii) は窓が全域のとき (ii)/mean と
一致する = **測定ではなく提示** (板 245 行の自己申告どおり「presentation 寄り」)。
ノイズ込みの生プロファイルの p-p は shading でも σ_col でもない。

**正典の序列 (推奨 — §7 でユーザ確認)**:

- **シェーディング (平坦度) の正典 = shading [%]** (2次面、除去の有無に
  関わらず同じ次数)。理由: 約束1 (カットオフを必ず言う) を満たす唯一の
  低周波指標で、provenance の必須欄を既に持つ。
- **縞の正典 = (a) の σ_col / σ_row [DN]** (着地後)。% 表示は補助。
- **見えている範囲の p-p は正典に入れない** — 窓に依存し provenance を
  持たない提示値。プロットの下の読取りに留め、export に載せない。報告書に
  貼りたい要望が出たら再訪 (そのときは窓を provenance で運ぶのが条件)。

この序列を本文に 1 段落で書く (§6-3)。書かないと「p-p 5% in view」が
シェーディングとして引用される — 名前の側で守る、が本書の家風である。
