# Browse パネル 全機能の棚卸しと要否判定

「まずボタンと機能を列挙して本当に必要か、どういう表示が正しいか」(2026-08-03)。
コード(core/main.cpp 16318-17700)から**実在するもの全部**を数えた。
判定の物差しは docs/browse-topbar-design.md §2.2 の収斂文法:

1. 定常クロームは1行、唯一の可読テキストはパス
2. パスは編集できる1本の行(箱の列ではない)
3. 絞り込みの常設入口は最大1つ、検索は召喚される
4. リモートは場所の属性。OK は沈黙し、異常だけが画素を得る
5. ジャンプ(bookmark/recent/host)は召喚、常設の場所を持たない
6. エンジンは場所が決める(ローカル=即時 / リモート=往復)

判定語: **残す**(常設で正しい) / **降格**(メニュー・キー・召喚へ) / **統合**(他と1つに) /
**廃止**(機能ごと不要、または他で完全に代替済み)

## B. リスト本体(行と列)

| 機能 | 現在 | 判定 | 正しい表示 |
|---|---|---|---|
| name 列 | 伸縮 | **残す** | 唯一の伸縮列。連番は `dark_0001-0480` と畳んで `[480]` を添える(実装済) |
| shape / dtype 列 | 固定幅 | **残す** | この道具の核心情報(積めるか否かが一目で判る)。狭いときも name の次に残す優先度 |
| size 列 | 固定幅 | **残す(優先度下)** | 幅が足りなければ最初に落とす |
| modified 列 | 固定幅 | **残す(Watch で昇格)** | Watch 導入後は「変わった行」を琥珀にする土台。落とすなら size の次 |
| 行クリック | 選択(可逆) | **残す** | 確定しない。既定の使い方 |
| ダブルクリック / Enter | 確定(開く・降りる) | **残す** | 唯一の確定手段 |
| シェブロン(tree) | 展開/畳み | **残す** | クリック域を行本体と分離済み。展開はダブルクリック経路で誤発火しない |
| `↑↓ Home End` | カーソル移動 | **残す** | — |
| `→ ←` | tree 展開/畳み | **残す** | — |
| `Backspace` | 親へ | **残す** | `^` と同義 |
| `Alt+← / Alt+→` | 履歴 | **残す** | mouse4/5 と同義 |
| `Ctrl+F` | filter へフォーカス | **統合** | 打鍵召喚チップの明示的な呼び出し(打鍵でも出る) |
| `, / .` | プレビュー frame 送り | **残す** | プレビュー使用時のみ |
| `..` 行 | 親へ戻る行 | **残す** | tree でも要る(木は降りるだけなので) |

## D. 判断が要る点(私の推奨つき)

1. **`grp|flat`・`list|tree` を `…` に落としてよいか。** 実使用頻度はユーザーのみ知る。
   → 推奨: **落とす。ただし既定でないときはチップで名乗る。** 頻繁と判れば1行目右端にアイコン寸で復帰。
2. **`>`(進む)をバーから消してよいか。** → 推奨: **消す**(`Alt+→`/mouse5 は残る)。
3. **`refresh` の降格。** Watch 実装後は自動更新が主になる。→ 推奨: **F5 + メニュー**。
4. **Temporal stats を選択バーに落とすか、右クリックだけにするか。**
   → 推奨: **選択バー**(複数選択して一気に走らせる使い方があるため)。
5. **空状態の再設計**(「接続」語彙の追放)。→ 推奨: **場所の一覧 + Open folder…**。
6. **Browse 行にも Reload from disk を出すか。** Browse は「ディスクの姿」なので
   refresh と意味が重なる。→ 推奨: **出さない**(Files 側だけ)。
