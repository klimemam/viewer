# 比較スロット (A, B, C, ...) の定義

いま動いている比較スロットの規約。画像側の見せ方そのものは
[manual.md](manual.md) §3b、数値側の仕様は [ab-stats-plan.md](ab-stats-plan.md)。

## 1. スロットとは何か【立場】

**スロットは「stack への参照 + follow 規約」である。画像そのものではない。**

`ed14f86` 以降、B もエクストラも同じ一つの規則 (`followFrame`) で解決される:

- ピン (メンバ frame の uid) が **stack を指名**し、クリックした frame は
  「follow が切れているときに見せる frame」を兼ねる。
- follow ON かつ両側 stack なら、**A のフレーム番号を持つ兄弟**が答え。
- 単発 frame は長さ1の stack として退化し、動かない (dark / golden sample)。
- A 自身の stack へのピンは follow しない (frame 対 frame 比較のため —
  Shift+B の流儀)。
- A の番号の frame が無ければ **diverged**: ピンした frame を [stale] 付きで
  見せる。黙って別番号を「対」として見せることは決してしない。

この定義から次が従う。

**A はスロットではない。カーソルである。** アプリ全体 (Inspector・Histogram・
Analysis・レンジスコープ) が `cur()` に紐づいており、A をピン化することは
項目28 が言う「`cur()` の単一性を壊す」問題そのもの。そこは項目28-4
(パネルを画像にピン留め) の話であって比較の話ではない。比較の文書としての
立場: **A = いま見ているもの、B.. = 留めたもの**。この非対称は仕様であり、
画面の言葉もそれで統一する (「A を動かす」「D を留める」)。

**1画像1文字。** 同じ画像が B と D を兼ねると、同じ画素が2枚のパネと2行の
表に出る。`ed14f86` で入れた規律 (既定 B は文字持ちを飛ばす / 明示指名は
昇格 = 文字を放す / B は文字を取れない) をそのまま正式仕様にする。

**文字は「位置」であって「名前」ではない。** D を外せば E が D になる
(tile selftest T7 が固定済み)。歯抜けの文字を保持する案は捨てる — 表・色・
キャッシュはすべて添字で紐づいており、歯抜けは「欠測」に見える。

## 2. follow とフレーム発散 (divergence)

**規則は全スロット共通で一つ** (`followFrame`)。スロットごとに独立に発散する:
C は frame 200 を持ち D は 150 で終わる、が普通に起きる (再撮で枚数が違う)。

見せ方 (実装済みを正式化):

- タイルのバッジ: `D  name  [stale]`。
- Projection / Temporal: 琥珀の注意行「follow-frame: slot D: no frame 200 in
  that stack …」。文は B の `g_abFollowDiverged` と同型 — **同じ主張には同じ
  語彙** ([stale])。
- 発散中の数値行は消さない。**ピンした frame の数値を出し、stale と言う**。
  消すと「D が壊れた」に読める。frame が戻れば (remote の遅着など) 黙って復帰。

## 5. 入る・出る・キー

`ed14f86` 後の形をそのまま正式仕様とする:

| キー | 動作 |
|---|---|
| `C` / `\` | モード巡回 Off → wipe → split → diff → flip → Off。**Off は常に A 単独** |
| `Shift+C` | Split を直接アーム = スロット一覧 (タイル)。スロット無しなら言う |
| `Shift+\` | A ↔ B swap (二重予約は解消済み。JIS は状態バーのボタン) |
| `Shift+B` | いまの frame を B にピン |
| `B` (押下中) | B を全画面フラッシュ (タイルより優先。既存) |

- スロットの**追加は Files 右クリックのみ**とする (文字を明記した項目)。
  修飾キー付きクリックのような不可視の入口は作らない (`caa5216` の判断を
  維持)。
- **出口は Off**。タイル中に C を3回でも、View メニューでも、必ず「A 単独」
  に着地する。スロット文字は Off でも Files と数値側に残る — 比較モードは
  見せ方であってスロットの生死ではない。

## 6. Files の見せ方

- 行頭の文字バッジ (実装済): frame 行はその frame の文字、stack 行は中の
  frame が持つ文字を**全部** (`BC` など)。B と同じインク・同じ視覚重量。
- 右クリック: `Add as compare slot D` / `Remove from compare slot D` /
  B 系項目 (既存)。B の行にはスロット項目を出さない (1画像1文字)。
- バッジをクリックで外す案は**採らない** — 行クリック (選択) との誤爆が
  読みより高くつく。
