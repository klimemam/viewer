# 用語と操作の定義 (frame / stack / batch)

機能を継ぎ足すうちに「Close は何を閉じるのか」「rename はどれに効くのか」が
場所ごとにバラバラになった。ここが正典。実装がこの表と違っていたらバグ。

## 3つの層

| 層 | 定義 | 実体 | 名前 |
|---|---|---|---|
| **frame** | 画素の入った1枚。測定の最小単位 | `ImageDoc` | ファイル名（変更不可） |
| **stack** | 同一条件で撮られた frame の並び。**時間軸を持つ**ので σ_t/FPN 分離・per-frame 表が意味を持つ | `SeqInfo` (`ImageDoc::seqId`) | 初期値=フォルダ/パターン、**リネーム可** |
| **batch (塊)** | 開いたものを人間が管理するための入れ物。**stack と単発 frame が混在してよい** | `App::Batch` (`ImageDoc::batchId`) | 初期値=フォルダ名、**リネーム可** |

包含関係は frame ⊂ stack ⊂ batch。ただし stack を経由しない frame（単発で開いた
1枚、`average.npy` のような代表画像）も batch に直接ぶら下がる。

### batch の役割は2つ

1. **素性の管理** — 「どこから・何のために開いた集まりか」を人間が名前で持つ。
   フォルダ名は初期値にすぎず、`root/00` と `root/01` を1つの batch にしても、
   同じフォルダを2回開いて別々の batch にしてもよい。**開いた操作 1回 = batch 1個**
   が既定で、フォルダ構造とは意図的に切り離してある。
2. **解析の区切り** — 測定・集計・エクスポート・一括操作の対象範囲。リニアリティが
   対象とする stack 群、per-frame テーブルの出力範囲、まとめて閉じる単位はすべて
   batch で指定できるべき。

## 操作マトリクス

「その操作をその層に対して行ったとき何が起きるか」。空欄はその層に対して
提供しない（＝UI に出さない）。

| 操作 | frame | stack | batch |
|---|---|---|---|
| **Close** | 単発 frame のみ閉じる。stack の一員なら**stack ごと閉じる**（1枚ずつ消えるのは誤り）。逃げ道: Ctrl+Alt+W はその1枚だけ | 全 frame + SeqInfo を破棄 | 含む stack / frame をすべて破棄 |
| **rename** | — (ファイル名) | 右クリック / F2。セッション保存 | ヘッダ右クリック。セッション保存 |
| **表示レンジ** | `View > Value range scope` = per frame | 同 = per stack（既定：基準フレームを共有） | 同 = everything（全体で共有） |
| **Temporal (σ_t/FPN)** | — （1枚に時間軸はない） | ここが本体。ローカル集計 or サーバー集計。**未オープンの stack（ブラウザ上のグループ）もサーバ集計可**、結果は `not opened` タグ付き | — （条件混在は平均に意味がない） |
| **per-frame 表 (TSV)** | 1行 | 全 frame の表。**σ_t 列は持たない**（stack の属性を frame 行に置くのは誤り） | 将来: batch 横断の表 |
| **リニアリティ** | — | 1 stack = 1 照度点 | fit の対象集合（**将来**。現在は全 stack が対象） |
| **preview** | 使い捨て枠1つ。昇格で通常の frame になる | 先頭 frame のみ preview | preview は専用の擬似 batch に居る |
| **compare (A/B)** | frame 対 frame | フレーム番号を保って stack 間比較 | — |
| **測定 (analyzer)** | 対象は現在の frame + ROI | 集計系は stack 単位 | — |

## 命名の規則（表示文字列）

- stack の既定名は `フォルダ/パターン`（例 `10lx/frame_???.npy`）。
  リニアリティの Auto levels はこの**フォルダ部**から照度を読む。
- パターンの `?` は**変化する桁のみ**を表す。変化しない数字は数字のまま残す
  （`gain10_???.npy`）。`#` は使わない（ImGui がラベルを `##` で切る）。
- 桁 run が**2本以上**変化する場合、`?` を2本並べる代わりに stack を分割する
  （条件混在の stack は σ_t が無意味）。
- batch の既定名は開いた根フォルダ名。

## 実装上の不変条件

- CFA プレーンは統計で決して混ぜない（R/Gr/Gb/B は常に別系列）。
- 部分ロードされた stack の集計は「何枚中何枚か」を必ず併記する。
- σ_t は stack の属性。frame の属性として出力しない。
- 1回の Open 操作は batch を1つだけ作る（**既定**。picker で「トップフォルダ毎」を
  指定した時のみ複数）。同じフォルダの再オープンは新しい batch になる。
- **batch 名は一意**。セッションは batch を名前で復元するため、衝突には ` (2)` を付す。
