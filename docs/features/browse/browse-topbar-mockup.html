案A 「一行+召喚」 定常1行

定常時 — 上部で読むものはパス1文だけ

trc2 — Browse
v<^ trc2: /data/run42/dark_1ms …
> 20260721_night
dark_0001-0480 [480]
flat_0001-0120 [120]
note.txt
type to filter · Ctrl+L path · … menu
  • ホストはルートクラム trc2: が一度だけ名乗る(ローカル時は無表示=沈黙)
  • 接続メニュー(切断/再接続/bookmark)はクラム右クリック。異常はリスト内インライン
  • 表示モード・refresh・~・+ は … メニューとキーへ

打鍵=絞り込みチップ召喚(可逆) → Enter=サーバ確定

trc2 — Browse
v<^ trc2: /data/run42/dark_1ms …
dark_2/4Esc
dark_0001-0480 [480]
dark_0481-0520 [40]
Enter: search server (recursive)…
trc2 — Browse
v<^ trc2: /data/run42 …
dark_*server ⟳Esc
run42/1ms/dark_0001-0480 [480]
run42/5ms/dark_0001-0480 [480]
run43/1ms/dark_0001-0120 [120]
  • 入口は1つ。打鍵中=クライアント側即時(選択と同じ可逆)、Enter=サーバ再帰(確定)
  • 既存のクリック=選択/ダブルクリック=確定の文法にそのまま載る → 入口②が構成的に消滅

300px でも崩れない

trc2 — Browse
v<^ trc2: …/dark_1ms …
dark_2/4
dark_0001-0480 [480]
dark_0481-0520 [40]
  • パスは中央省略、ナビ3個+…は固定。チップはリスト上に浮くので幅を奪わない

案B 「二段固定・単一スロット」 定常2行

通常 — 1行1役の2行

trc2 — Browse
v trc2: /data/run42/dark_1ms
<^ filter (Ctrl+F) 34/512…
> 20260721_night
dark_0001-0480 [480]
flat_0001-0120 [120]

検索召喚時 — 同一スロットを乗っ取る(2箱は同時に存在しない)

trc2 — Browse
v trc2: /data/run42/dark_1ms
<^ search: frame_** Stop範囲:この下…
1ms/frame_0001.npy
5ms/frame_0001.npy
  • 絞り込みの発見可能性は最大(箱が見えている)
  • 収斂値(1行)より1行重い。300px では filter 箱が窮屈。モード誤認の芽(ラベル+Escで抑える)

案C 「ローカル/リモート分離」 local 1行 / ssh 2行

リモート専用パネル

Browse (ssh)
trc2[ssh] 切断…
v<^ /data/run42
dark_0001-0480 [480]
  • 「接続OKは沈黙」に違反 — OK状態にホスト行が恒久的に1行を支払う
  • 即時絞り込み+召喚検索は結局必要 = 案Aの解を内包。文法の二重実装
  • サーベイ4系統で局所性によりパネルを分けた例はゼロ(二面板は転送動詞の産物)
