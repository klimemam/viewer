# 平坦画像を前提とする統計の整理と、シェーディング除去の位置づけ

> **状態: 議論用の叩き台。設計にも実装にも落とさないこと。**

> 内容の整理と数式の検算は済んでいるが、**何をどの順で作るか、画面に何を
> どの名前で出すかは未決**。決めるべき論点は `docs/todo-open.md` の項目16。
> この文書を根拠に実装を始めない。

`docs/stats-taxonomy.md` は測定を **入力の数**(1枚 / stack / series)で分類して
いる。この文書はそこに **もう1本の軸** を足す:

> その測定は **シーンに何を仮定しているか**。

この軸を分けないと「平坦でないと嘘になる量」と「シーンに依存しない量」が同じ
表に並び、フラットでない画像に対して平気で PRNU を出してしまう。

## 0. まず、平坦を要求しない量を切り分ける

**σ_t (時間ノイズ) は、画素ごとの値としては平坦画像を必要としない。**
絵柄は時間方向に定数なので、per-pixel の σ_t 推定からは落ちる。

**ただし「だからシェーディングと無関係」は誤り。** σ_t 自身がショットノイズ経由で
信号レベルに依存する (σ_t² ≈ σ_read² + K·μ)。30% のシェーディングがあれば周辺の
ショット分散は 30% 低い — **σ_t マップにはシェーディングがはっきり出る**。
落ちるのは1次モーメントであって2次モーメントではない。

したがって:
- σ_t の**マップ**は任意の静止シーンで測れる。
- **スカラーの σ_t** (仕様比較、PTC、後述の `−σ_t²/N` 補正に使う値) は
  **単一レベル = 平坦を要求する**。信号レベルが混ざった平均は解釈できない。
- 「静止」はフラットより厳しい要求でもある。絵柄があると微小な振動や
  フォーカスドリフトが**勾配に比例した見かけの時間ノイズ**になる。
- 局所的に飽和・クリップした領域では σ_t が潰れる。

逆に **空間方向の σ は全部シーンを見てしまう**。だから平坦が要る。

| 仮定 | 量 |
|---|---|
| 静止していればよい (絵柄可) | σ_t、per-frame の平均ドリフト / フリッカ、RTS/blink |
| **平坦が要る** | σ_fpn、DSNU、PRNU、行/列ノイズ、シェーディング、欠陥画素の閾値判定 |
| 特定チャートが要る | SFR/MTF、OECF、dead-leaves |

以下 (a)(b)(c) は **平坦を要る側** の話。

## (a) 平坦な 1 frame が前提の統計

### 出せる量

| 量 | 式 | 単位 |
|---|---|---|
| σ_total (プレーン別 空間σ) | 全画素の標準偏差 | DN |
| σ_col (列ノイズ = 縦縞) | `var(列平均) − σ_p²/H` の平方根 | DN |
| σ_row (行ノイズ = 横縞) | `var(行平均) − σ_p²/W` の平方根 | DN |
| σ_p (画素ランダム) | `(T − A − B) / (1 − 1/H − 1/W)` の平方根 | DN |
| 比 | `σ_col/σ_p`、`σ_row/σ_p` | 無次元 |
| シェーディング | 低周波成分の p-p / 中心比 | % |
| 欠陥画素 (簡易) | 局所中央値からの外れ | 個 / ppm |

`T=σ_total²`, `A=var(列平均)`, `B=var(行平均)`。W,H は**プレーンの**寸法
(Bayer なら w/2, h/2)。純ランダムを入れると σ_col=σ_row=0 に戻ることを
必ずテストする (数値検証済み)。

#### 推定量としての注意 (数値検証で確認した実際の落とし穴)

- **画素をマスクすると行/列の相殺が厳密でなくなる。** 上の式は「どの列も同じ行
  集合を張る」ことに依存している。飽和・欠陥画素を除外した瞬間にこれが崩れ、
  **存在しない列ノイズが湧く** (漏れ量 ≈ `σ_row·√(f/H)`、f=マスク率)。
  ランダムなマスクなら軽微だが、**飽和した塊や列単位の欠損**という現実的な
  ケースでは効く。対策: 列ごとの実サンプル数 `H_x`・行ごとの `W_y` を使う、
  または行/列ごと丸ごと除外する。
- **`T = σ_p² + σ_col² + σ_row²` は漸近形。** 厳密には (ddof=1)
  `E[T] = σ_p² + σ_col²·H(W−1)/(HW−1) + σ_row²·W(H−1)/(HW−1)`、
  つまり `σ_col²/W + σ_row²/H` だけ低い。1000² では無視できるが、
  **小さな ROI や Bayer プレーンでは効く**。
- **ddof を混ぜない。** A, B は ddof=1 で不偏。T を ddof=0 で取ると
  O(1/W) の不整合が戻ってくる。どれを使うか決めて統一する。
- **負値と退化を必ずガードする。** `T−A−B` も `A − σ_p²/H` も推定誤差で負に
  なりうる。H=W=2 では `1 − 1/H − 1/W = 0` で発散する。0 でクランプし、
  クランプしたことを結果に出す (黙って 0 を返さない)。

### この層の限界 — ここを言わないと嘘になる

**1枚では時間ノイズと固定パターンが分離できない。** 測っているのは常に

    σ_spatial² = σ_t² + σ_fpn²

なので、ここで出る σ_col も σ_row も σ_p も **「時間ゆらぎ + 固定」の合成**。
したがって:

- **この層の PRNU は proxy であって EMVA の PRNU ではない**
  (現 plugin `uniformity/prnu-fpn` が既にそう明記している)。
- 固定パターンとしては **上界** にしかならない。「これ以下」とは言えるが
  「これが固定成分だ」とは言えない。
- 画面表記は `PRNU (proxy, 1 frame: 時間ノイズ込み)` のように**層を明示**する。

## (b) 平坦な stack が前提の統計

時間軸が入って初めて **分離** ができる。ここが本丸。

### 分離の基本形

    ⟨σ_t²⟩  = 画素ごとの時間分散の平均 (分散の平均。σ の平均の2乗ではない)
    M(x,y)  = N フレームの平均画像
    σ_fpn²  = var_spatial(M) − ⟨σ_t²⟩/N            (固定パターン)

**`− ⟨σ_t²⟩/N` を忘れないこと。** N 枚平均しても時間ノイズは √N でしか落ちない。
これは (a) の `− σ_p²/H` と**同じ構造の補正**で、同じ理由で忘れられる。
N=16、σ_t=10 DN なら残差 2.5 DN。**二乗和で効く**ので、真の FPN が 5 DN なら
`√(25+6.25) = 5.59 DN` と読める (7.5 ではない)。

補正の細部 — ここを外すと補正したつもりで外れる:

- **分散の平均であって、σ の平均の2乗ではない。** 後者は Jensen の不等式で
  `Var_spatial(σ_t)/N` だけ引き足りず、σ_fpn を**高く**出す。σ_t が画素で
  ばらつくほど効く (数値検証済み)。
- **画素ごとの時間分散は ddof = N−1 で取る。** ddof=0 だと補正量が (N−1)/N 倍
  になり、N=16 で 6.25% 引き足りない。
- **dark 減算をしたなら、dark 側の残差も引く。**
  `σ_fpn² = var_spatial(M_flat − M_dark) − ⟨σ_t,flat²⟩/N − ⟨σ_t,dark²⟩/N_dark`。
  dark stack の時間ノイズも √N_dark でしか落ちていない。片方だけ引くと
  (N=16, N_d=8, σ_t,dark=3 DN で) 分散が 4.5% 高く出る。

### 出せる量

| 量 | 必要な入力 | 備考 |
|---|---|---|
| σ_t | 同条件 ≥2 枚 | 平坦不要。stack の性質であって frame の性質ではない |
| σ_fpn | 同上 | 上の補正込み。平坦が要る |
| **DSNU** | **dark** stack | σ_fpn の dark 版。**DN で出すならここ。EMVA の e⁻ 表記には K が要る = series 層** |
| **PRNU** | **flat stack + dark stack** | 下記のとおり EMVA は分散の差で定義する |
| **列 FPN と時間的行ノイズの分離** | flat stack | 下記。これが stack の一番の価値 |
| 時間平均フレーム | 同上 | serve 内部では計算済み、出力口が無いだけ |
| 欠陥画素 (正式) | dark stack (+ flat stack) | hot / dead / RTS を区別できる |
| RTS / blink | ≥50 枚 | 画素毎の時系列が要る |

### 縞ノイズの「固定か、揺らいでいるか」

対策が違うので、これは分けないと意味がない:

- **列 FPN** — 縞が動かない。読み出し回路の列ごとのオフセット。
  平均画像 M に対して (a) の分解を掛ければ出る。
- **時間的な行ノイズ (ラインノイズ)** — フレームごとに縞が変わる。電源変動など。
  **各フレームで** σ_row を出し、その**時間ばらつき**を見る。

    σ_row,fix   = 平均画像 M の行ノイズ
    σ_row,temp  = 各フレームの (I_k − M) の行ノイズ、フレーム方向に RMS
                  × √(N/(N−1))        ← I_k は M に含まれるので、この係数が要る

**「フレーム毎の σ_row の時間ばらつき」は誤った推定量。** 各フレームの σ_row は
毎回同じ期待値を持つので、その時間 σ は推定量のジッタ (∝ 1/√H) を測るだけで、
時間的行ノイズの振幅にならない。数値検証: 真値 6.0 DN に対して、誤った方法は
0.245、正しい方法は 5.996 を返す。

現状のアプリはどちらも出していない。stack があるのに1枚分の情報しか使っていない。

## (c) 平坦な series (レベル掃引) が前提の統計

series = 条件を1つ振った stack の並び。ここでの条件は **光量**。

### 既に実装済み

linearity fit (感度・offset・LE max)、conversion gain K (PTC)、read noise。

### この層でしか出せない、まだ無い量

| 量 | なぜ series が要るか |
|---|---|
| **SNR カーブ** | 各レベルの mean と σ_t。**素材は linearity の行に既にある** |
| **DSNU と PRNU の分離** | 下記。単発の flat より遥かに堅い |
| ダイナミックレンジ | 飽和と読み出しノイズの比。飽和の定義が要る |
| 飽和容量 (full well) | K と飽和レベルから |

### 加法性と乗法性の分離 — series の本当の価値

固定パターンには**信号に比例する成分 (PRNU)** と **しない成分 (DSNU)** がある:

    σ_fpn²(μ) = DSNU² + (PRNU · μ)²        PRNU は無次元、DSNU と PRNU·μ は DN

**1つの flat レベルだけでは、この2つは分離できない。** レベルを振って上式を
フィットすれば両方が出る。しかも各点が独立の測定なので、単発より信頼できるし、
残差を見れば「本当にこのモデルか」を確認できる。

- **フィットは `σ_fpn²` を `μ²` に対する線形回帰**にする (切片 = DSNU²、
  傾き = PRNU²)。厳密かつ安定で、非線形フィットを回す必要がない。
- **μ は dark 補正後の平均**を使う。
- **加法と乗法が無相関である仮定**の上に成り立つ。列アンプのばらつきなどは
  両者を相関させ、正しくは `DSNU² + 2ρ·DSNU·PRNU·μ + (PRNU·μ)²`。
  無相関を仮定していることを明記する。
- **掃引は露光時間ではなく光量で行う。** 露光時間で振ると暗電流で DSNU 自体が
  動き、切片が定数でなくなってフィットが無意味になる。
- **各レベルで `−⟨σ_t²⟩/N` を必ず掛けてから**フィットすること。省くと
  `μ` に比例する項 (ショットノイズ/N) が混入し、モデルが表現できないので
  **ほぼ全部が切片に吸われる**。数値検証: 真値 DSNU 3.0 に対し、補正を省くと
  **4.87 (+62%)** になる一方 PRNU は 1.200→1.240% とほぼ無傷。
  つまり症状は「DSNU だけが大きく出る」。

これは既にある series 層 (`App::Series`、`Series::members`、値と単位) に
**そのまま乗る**。新しい階層は要らない。

### EMVA 1288 を名乗るなら (未検証・要確認)

**この節は標準の原文に当たって確認すること。** 以下は構造としては確かだが、
版 (3.1 / 4.0) による差、推奨動作点、規定と参考の別までは確認していない。
**確認せずに画面に "EMVA 1288" と書かない。**

記憶している形:

    DSNU_1288 = s_y.dark / K                      [e⁻]
    PRNU_1288 = √(s²_y.50 − s²_y.dark) / (μ_y.50 − μ_y.dark)   [%]

ここから来る、この文書の (b) 節との差:

- **PRNU は「dark 補正後の平均画像の空間σ ÷ 平均信号」ではない。** EMVA は
  **分散を引き算**する。画素ごとに dark を引いてから σ を取る方式は
  `μ²·var(gain)` を厳密に与えるが、EMVA 式には交差項 `2μ·cov(offset, gain)`
  が残る。**無相関なら一致し、そうでなければ別の推定量**。どちらを実装したか
  を明記する (同じ名前で違う量を出さない)。
- **DSNU を e⁻ で出すには K が要る。** K は photon transfer = **series** から
  しか出ない。したがって「DSNU は stack 層」は DN で出す場合に限る。
- 標準準拠を名乗るには動作点 (≈50% 飽和)、L 枚平均、
  **空間周波数スペクトログラム / 高域通過版の報告**まで要る。
  「dark stack と flat stack があること」は必要条件であって十分条件ではない。
  後述の「カットオフを必ず言う」は、この要求と同じ話。

### 「flat」「dark」は宣言であって推論ではない

現状 linearity は **level 0 を dark とみなす**規則で部分的に動いている。
DSNU/PRNU をやるなら、これは持たない。必要なのは:

- stack のメタとして **「これは dark」「これは flat」** を持つ (series の member 属性)
- dark が無ければ **DSNU も PRNU も出さない**。0 で代用しない
  (series の「未設定値は 0 として fit に入れない」と同じ原則)

| | 1 frame (平坦) | stack (平坦) | series (平坦・多レベル) |

| σ_t | — | ここが本体 | レベル毎に |

## シェーディング除去 — 全部の土台に置く

### なぜ「機能」ではなく「段」なのか

現実に完全な平坦照明は無い。レンズのシェーディング、照明ムラ、IR カットの角度
依存が必ず乗る。そして **上の (a)(b)(c) の空間統計は全部これを拾う**。
だからシェーディング除去は個々の測定のオプションではなく、
**空間統計の前段に共通して置く1つの処理**にする。

    PlaneView → detrend(method, params) → PlaneView → 統計

これは共有測定カーネル (`TODO_one_implementation.md`) の設計にそのまま入る。
入口が1つなら、ローカルとピアで違う除去をしてしまう事故も構造的に防げる。

### 方式

| 方式 | 内容 | 向き |
|---|---|---|
| **多項式面フィット** | 2〜4次の面を最小二乗で当てて除算(乗法)/減算(加法) | 滑らかなレンズシェーディング |
| **ブロック中央値** | N×N ブロックの中央値で低周波面を作り除去 | 欠陥画素や絵柄に頑健 |
| **参照フラット除算** | 既知の良品フラットで割る | 照明ムラごと落とせる。参照の管理が要る |
| **隣接差分** | 隣の行/列との差を取る | 行/列ノイズ専用。滑らかな傾きが厳密に消える |
| なし | 生のまま | フラット性が保証された治具のとき |

### 外せない設計上の約束

1. **カットオフを必ず言う。** PRNU も σ_fpn も**空間周波数帯の関数**であって、
   「PRNU = 1.2%」だけでは再現できない。「4次面除去後」「64px ブロック除去後」
   まで含めて1つの測定値。**結果と一緒に必ず表示・保存する。**
2. **プレーンごとに独立に除去する。** シェーディングはプレーンで違う
   (**色シェーディング**は実在の現象で、それ自体が測りたい量になる)。
   R の面で B を割ってはいけない。
3. **σ_t には適用しない — ただし理由を間違えないこと。** シェーディングは
   σ_t の**マップには出る** (ショットノイズが信号レベルに依存するため。§0)。
   それでも除去を掛けないのは、σ_t が測っているのが**時間方向のばらつき**で
   あって空間分布ではないから。空間的な面を引いても時間ノイズは変わらず、
   引いた分だけ意味が濁る。**detrend は空間統計にだけ掛かる段**とする。
   σ_t の空間依存を扱いたいなら、それは detrend ではなく
   **ROI を切る / レベル別に見る**という別の操作。
4. **除去した面そのものを出力にする。** シェーディング量 (中心比 %、p-p) は
   捨てるべきノイズではなく**測りたい量**。除去して終わりにしない。
5. **除去前後の両方を出す。** 「除去でどれだけ減ったか」が、そもそも除去が
   妥当だったかの判断材料になる。
6. **ノイズ統計には減算型を優先する。** 面で**除算**すると、周辺のノイズが
   1/s 倍に増幅されて**分散が場所によって変わる**。(a) の分解も
   「⟨画素毎時間分散の平均⟩」も**分散が一様であること**を前提にしているので、
   除算した画像にそのまま掛けると前提が崩れる。除算が必要なら
   (乗法性のシェーディングを扱うなら) 分散マップを s² で正規化し直す。

### 順序 (この順でしか安全に積めない)

0. **黒レベル / OB クランプの整合**(フレーム毎に黒が動くなら、dark 減算は
   その前に壊れている。dark 減算より前に来る唯一のもの)
1a. **飽和・クリップのマスク — 必ず生値で。** dark を引いたりゲインで割った
   後では飽和レベルが一定の DN でなくなり、飽和画素が識別できなくなる。
2. **dark 減算**(加法成分を先に落とす)。**順序は入れ替えられない**:
   `y = d + s·g·μ` を先に s で割ると `d/s + g·μ` となり、**平坦だった
   オフセットにシェーディングの逆パターンが焼き付く**。
2b. **リニアリティ補正**(非線形が大きい場合)。乗法的シェーディングのモデルは
   線形性を前提にしている。
3. **シェーディング除去**(方式とパラメータを記録)
3b. **欠陥画素のマスク — detrend の後で。** 欠陥は暗基準に対する外れなので、
   シェーディングの乗った生画像に大域的な外れ値検定を掛けると**四隅が
   欠陥に見える**。面フィットと欠陥検出は相互依存なので、
   **フィット → σクリップ → 再フィット**の反復にする。
4. **統計**(プレーン別)

**この列は一本道ではなく分岐する。** σ_t は 3 の**前**(detrend しない、上の
約束3)、空間統計は 3 の**後**。1本の線に描くとこの分岐が隠れる。

**1a でマスクした瞬間、(a) の行/列の厳密な相殺が崩れる**(上述)。
4 では列ごと `H_x`・行ごと `W_y` の実サンプル数を使うこと。

## 実装の進め方 (提案)

一度に作らない。**共有測定カーネルの最初の題材にする**のが筋がよい。

1. `temporalStats` をカーネルに出す (既に決めた第一歩)。σ_t と、
   **`−σ_t²/N` 補正込みの σ_fpn** をここで確定させる。
2. (a) の分解 (σ_p/σ_row/σ_col) を純関数として足す。合成データで検算する
   単体テストを同時に書く — 既知の σ_p のみ → 比が 0、既知の行オフセット →
   σ_row がそれを回収、W/H を変えても不変。
3. `detrend` を段として足す。まず多項式面とブロック中央値の2つ。
   パラメータを結果構造体に**必須フィールド**として持たせる (表示側が省略できない)。
4. stack の縞分離 (固定 / 時間) を足す。
5. series の `σ_fpn(μ)` フィットで DSNU/PRNU を分離。ここで初めて
   「dark である」「flat である」の宣言をメタとして入れる。
6. SNR カーブ (素材は既にあるので、実は 1 の直後でも出せる)。

各段で **local と peer が同じカーネルを呼ぶ**ことを parity で確認する。
