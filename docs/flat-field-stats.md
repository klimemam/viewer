## 0. まず、平坦を要求しない量を切り分ける

**σ_t (時間ノイズ) は、画素ごとの値としては平坦画像を必要としない。**
絵柄は時間方向に定数なので、per-pixel の σ_t 推定からは落ちる。

**ただし「だからシェーディングと無関係」は誤り。** σ_t 自身がショットノイズ経由で
信号レベルに依存する (σ_t² ≈ σ_read² + K·μ)。30% のシェーディングがあれば周辺の
ショット分散は 30% 低い — **σ_t マップにはシェーディングがはっきり出る**。
落ちるのは1次モーメントであって2次モーメントではない。

したがって:
- σ_t の**マップ**は任意の静止シーンで測れる。
- **スカラーの σ_t** (仕様比較、PTC、後述の `−σ_t²/N` 補正に使う値) は
  **単一レベル = 平坦を要求する**。信号レベルが混ざった平均は解釈できない。
- 「静止」はフラットより厳しい要求でもある。絵柄があると微小な振動や
  フォーカスドリフトが**勾配に比例した見かけの時間ノイズ**になる。
- 局所的に飽和・クリップした領域では σ_t が潰れる。

逆に **空間方向の σ は全部シーンを見てしまう**。だから平坦が要る。

| 仮定 | 量 |
|---|---|
| 静止していればよい (絵柄可) | σ_t、per-frame の平均ドリフト / フリッカ、RTS/blink |
| **平坦が要る** | σ_fpn、DSNU、PRNU、行/列ノイズ、シェーディング、欠陥画素の閾値判定 |
| 特定チャートが要る | SFR/MTF、OECF、dead-leaves |

以下 (a)(b)(c) は **平坦を要る側** の話。

## (a) 平坦な 1 frame が前提の統計

### 出せる量

| 量 | 式 | 単位 |
|---|---|---|
| σ_total (プレーン別 空間σ) | 全画素の標準偏差 | DN |
| σ_col (列ノイズ = 縦縞) | `var(列平均) − σ_p²/H` の平方根 | DN |
| σ_row (行ノイズ = 横縞) | `var(行平均) − σ_p²/W` の平方根 | DN |
| σ_p (画素ランダム) | `(T − A − B) / (1 − 1/H − 1/W)` の平方根 | DN |
| 比 | `σ_col/σ_p`、`σ_row/σ_p` | 無次元 |
| シェーディング | 低周波成分の p-p / 中心比 | % |
| 欠陥画素 (簡易) | 局所中央値からの外れ | 個 / ppm |

`T=σ_total²`, `A=var(列平均)`, `B=var(行平均)`。W,H は**プレーンの**寸法
(Bayer なら w/2, h/2)。純ランダムを入れると σ_col=σ_row=0 に戻ることを
必ずテストする (数値検証済み)。

**ddof は全部 ddof=1 で統一する** — T も A も B も。混ぜると O(1/W) の
不整合が戻る (下の注意)。この規約は (b)(c) の空間分散にもそのまま掛かる。

### 住所と表記 (確定分 + 判断1)

この分解は**役割を要しない中立量**なので General の frame 層に住む —
掛ける相手が時間平均 frame (stack の畳み込み、PR #99) なら、それがそのまま
analysis-layers.md §3.2 の「Stack Projection は平均画像の行/列 FPN」になる。
新しいパネルは要らない。

表示キーは**測った物の名前**で出す (判断1):

    sigma_p [DN] / sigma_row [DN] / sigma_col [DN]

- 凡例 (ツールチップ) に説明語を添える: 「sigma_row = 行平均のばらつき =
  **横縞** (horizontal banding)」「sigma_col = 列平均のばらつき = **縦縞**
  (vertical banding)」。
- **RN / HRN / VRN は列名にしない。** HRN が行か列かは**ベンダで逆**になる。
  凡例に載せる場合も「ベンダにより H/V の意味が逆」の1文を必ず添える。
- 既存の中立名の先例 (`sigma_t [DN]`、`std / mean [%]`) と同じ流儀:
  ASCII キー + 単位、量の主張は名前でしない。

### 推定量としての注意 (数値検証で確認した実際の落とし穴)

- **画素をマスクすると行/列の相殺が厳密でなくなる。** 上の式は「どの列も同じ行
  集合を張る」ことに依存している。飽和・欠陥画素を除外した瞬間にこれが崩れ、
  **存在しない列ノイズが湧く** (漏れ量 ≈ `σ_row·√(f/H)`、f=マスク率)。
  ランダムなマスクなら軽微だが、**飽和した塊や列単位の欠損**という現実的な
  ケースでは効く。対策 (規範): 列ごとの実サンプル数 `H_x`・行ごとの `W_y` を
  使う、または行/列ごと丸ごと除外する。
- **`T = σ_p² + σ_col² + σ_row²` は漸近形。** 厳密には (ddof=1)
  `E[T] = σ_p² + σ_col²·H(W−1)/(HW−1) + σ_row²·W(H−1)/(HW−1)`、
  つまり `σ_col²/W + σ_row²/H` だけ低い。1000² では無視できるが、
  **小さな ROI や Bayer プレーンでは効く**。
- **ddof を混ぜない。** A, B は ddof=1 で不偏。T を ddof=0 で取ると
  O(1/W) の不整合が戻ってくる。上で ddof=1 に統一した。
- **負値と退化を必ずガードする。** `T−A−B` も `A − σ_p²/H` も推定誤差で負に
  なりうる。H=W=2 では `1 − 1/H − 1/W = 0` で発散する。0 でクランプし、
  **クランプしたことを結果に出す** (黙って 0 を返さない)。この規約は (b)(c) の
  `max(0, …)` すべてに掛かる。

### この層の限界 — ここを言わないと嘘になる

**1枚では時間ノイズと固定パターンが分離できない。** 測っているのは常に

    σ_spatial² = σ_t² + σ_fpn²

なので、ここで出る σ_col も σ_row も σ_p も **「時間ゆらぎ + 固定」の合成**。
したがって:

- **この層に PRNU を名乗る数は無い。** 凍結中に名前の側が確定した:
  ROIs の旧 `PRNU [σ %]` は **`std / mean [%]`** に改名済み (General から
  有名名が消えた)、plugin `uniformity/prnu-fpn` の `prnu_pct` は **proxy を
  自己申告する修飾名**の Specific として残る (analysis-layers.md §7)。
- 固定パターンとしては **上界** にしかならない。「これ以下」とは言えるが
  「これが固定成分だ」とは言えない。
- (a) の分解を時間平均 frame に掛けた場合は別 — それは (b) の
  「列 FPN」の推定になる (由来を provenance が運ぶ)。

## (b) 平坦な stack が前提の統計

時間軸が入って初めて **分離** ができる。ここが本丸。

### 分離の基本形 — 推定量の確定 (判断2)

記号: 有効枚数は **画素ごと** に `n_i` (NaN は画素ごとに除外して数える —
`computeStackStats` / serve.cpp で確立済みの規約)。全画素で揃っていれば
`n_i ≡ N`。

    M(x,y)   = 画素ごとの時間平均 (n_i 枚)
    s_t,i²   = 画素ごとの時間分散、ddof = n_i − 1
    ⟨σ_t²⟩   = mean_i( s_t,i² )            … 分散の平均。σ の平均の2乗ではない
    σ_t      = sqrt(⟨σ_t²⟩)
    C        = mean_i( s_t,i² / n_i )      … 補正項。n_i ≡ N なら ⟨σ_t²⟩/N
    σ_fpn²   = max(0, var_spatial(M) − C)  … var は ddof=1。クランプは申告

**`− C` を忘れないこと。** N 枚平均しても時間ノイズは √N でしか落ちない。
これは (a) の `− σ_p²/H` と**同じ構造の補正**で、同じ理由で忘れられる。
N=16、σ_t=10 DN なら残差 2.5 DN。**二乗和で効く**ので、真の FPN が 5 DN なら
`√(25+6.25) = 5.59 DN` と読める (7.5 ではない)。

**適用先 (判断2): Temporal パネル / `MOP_TEMPORAL_STATS` の `sigma_fpn` 行
そのものを補正済みにする。** 確定時点の実装 (`recomputeTemporalIfNeeded` /
`runTemporalStats`) は補正なしの「時間平均の空間σ」を σ_fpn と呼んでおり、
それは名前が主張する量の推定量ではなく上界であった
(**実装は PR #124 で着地 — 文末「適用ノート」**)。補正後:

- `sigma_fpn [DN]` = 上式 (補正済み)。method 行 / TSV コメントに
  「temporal residual C subtracted」とクランプの有無を申告する。
- **補正なしの「畳んだ平均画像の空間σ」は消えない** — それは Stack ROIs の
  `sigma [DN] (mean_t)` 列 (畳み方修飾つきの中立名) として残る。別の量には
  別の名前が付いているだけである。
- これは analysis-layers.md §3.2 の「Stack ROIs の σ 列は Temporal パネルの
  σ_fpn と**同じ数**」の一文と食い違っていた。判断2 の確定を受けて正典側を
  「**同じ蓄積器**から出る (σ_fpn は補正を申告する)」に**1行修正した**
  (2026-08-09 適用 — 文末「適用ノート」)。黙って矛盾させない。蓄積器 (sum / sum² / cnt) が共通である事実は変わらず、
  「絵の下の数と表の数が食い違えない」は名前の側 (`(mean_t)` 修飾 vs
  補正申告つき `sigma_fpn`) が担う。

補正の細部 — ここを外すと補正したつもりで外れる:

- **分散の平均であって、σ の平均の2乗ではない。** 後者は Jensen の不等式で
  `Var_spatial(σ_t)/N` だけ引き足りず、σ_fpn を**高く**出す。σ_t が画素で
  ばらつくほど効く (数値検証済み)。
- **画素ごとの時間分散は ddof = n_i−1 で取る。** ddof=0 だと補正量が
  (N−1)/N 倍になり、N=16 で 6.25% 引き足りない。
  **【コード実査 2026-08-07】ここに local/peer の実在の食い違いがある**:
  serve.cpp (`runTemporalStats`) は ddof=1、local
  (`core/app/temporal_model.inc` の `recomputeTemporalIfNeeded`) は ddof=0。
  同じ stack の σ_t が local と server で √((N−1)/N) 倍ずれる。
  **parity 違反として local を ddof=1 に直すことは確定済み (判断3)。ただし
  コードの修正は本書とは別の PR が持つ** — 本書が確定させたのは規約
  (画素ごとの時間分散は ddof = n_i−1、local と peer は同じ算術を通る) の
  方であって、この一文はもう未決の問いではない。
- **n_i が画素で違うなら補正も画素ごと。** 補正項は `mean(s_t,i²/n_i)` で
  あって `⟨σ_t²⟩/mean(n_i)` ではない。蓄積器は per-pixel の cnt を既に
  持っているので追加コストは無い。
- **dark 減算をしたなら、dark 側の残差も引く。**
  `σ_fpn² = var_spatial(M_flat − M_dark) − C_flat − C_dark`。
  dark stack の時間ノイズも √N_dark でしか落ちていない。片方だけ引くと
  (N=16, N_d=8, σ_t,dark=3 DN で) 分散が 4.5% 高く出る。
- `σ_tot = sqrt(⟨σ_t²⟩ + σ_fpn²)` の定義は変えない。補正後はむしろ
  「1枚の空間σの期待値」として初めて正確になる (補正前は σ_t²/N を
  二重に数えていた)。

### 出せる量

| 量 | 必要な入力 | 備考 |
|---|---|---|
| σ_t | 同条件 ≥2 枚 | 平坦不要。stack の性質であって frame の性質ではない |
| σ_fpn | 同上 | **補正込み (判断2)**。平坦が要る |
| **DSNU** | **dark** stack | σ_fpn の dark 版。**DN で出すならここ。e⁻ 表記には K が要る = sweep 役割を足す**。住所は SetAnalyzer `{"dark": Stack()}` |
| **PRNU (直接)** | **flat stack + dark stack** | 下記「直接 DSNU / PRNU」。住所は SetAnalyzer `{"image": Stack(), "dark": Stack()}` |
| **列 FPN と時間的行ノイズの分離** | flat stack | 下記。これが stack の一番の価値 |
| 時間平均フレーム | 同上 | **出力あり (PR #99)**: Open frame average / sum。manual.md §5.2c |
| 欠陥画素 (正式) | dark stack (+ flat stack) | hot / dead / RTS を区別できる。SetAnalyzer `{"dark": Stack(), "flat"?: Stack()}` — 本書の範囲外 (map の器は #49) |
| RTS / blink | ≥50 枚 | 画素毎の時系列が要る。stack シグネチャの Specific (min_frames 大) |

### 直接 DSNU / PRNU — set の上の式 (判断4)

役割スキーマと名乗りは analysis-layers.md §6 の表のとおり (本書は式だけを
確定する)。**両役割とも Stack (min_frames ≥ 2) を要求する** — 1枚の frame では
s_t が取れず補正が引けない。frame を束ねた set では実行せず、理由1文で拒否する
(「1 frame has no time axis - the −σ_t²/N correction needs a stack」)。
§1 の役割例に `Frame()|Stack()` とあるのは AnalysisSet 型一般の例示で、
この解析のスキーマは Stack 限定 — スキーマは解析が宣言する (同 §1.5)。

**DSNU [DN]** — `{"dark": Stack()}`:

    DSNU = sqrt( max(0, var_spatial(M_dark) − C_dark) )        … プレーン別

= dark stack に対する補正済み σ_fpn そのもの。実装は Temporal の蓄積器の
再利用 (§6 の合成則のまま)。dark に detrend は掛けない (照明が無いので
シェーディングの概念が無い。暗部の低周波むら — 温度勾配など — は DSNU の
一部であって除去対象ではない)。

**PRNU [%] (直接)** — `{"image": Stack(), "dark": Stack()}`。
**式は画素毎減算形で確定する (判断4):**

    D(x,y)  = M_flat(x,y) − M_dark(x,y)                        … プレーン別
    σ_d²    = max(0, var_spatial(D) − C_flat − C_dark)
    μ       = mean_spatial(M_flat) − mean_spatial(M_dark)
    PRNU    = 100 · σ_d / μ    [%]        (μ ≤ 0 なら出さない。理由1文)

選ばなかった形 = **分散差** (記憶している EMVA の形、未検証):
`sqrt(s²_flat − s²_dark) / (μ_flat − μ_dark)`。線形モデル
`y = d + g·μ` の下で画素毎減算は `μ²·var(g)` を**厳密に**与えるのに対し、
分散差には交差項 `2μ·cov(offset, gain)` が残る (列アンプ等で offset と gain は
実際に相関する)。加えて画素毎減算は着地済み機構の合成そのもの
(fold → dark 減算 → 空間σ。analysis-layers.md §6 の実装列と一致) で、
減算後の平均画像 D がそのまま map 素材になる (器は #49)。
**分散差形は EMVA 照合が済んだ後に別名の量として足す**候補であって、
同じ PRNU の名前で差し替える対象ではない — どちらを実装したかは結果が言う。

出力の名乗り (正典の不変条件どおり): 裸の `PRNU` / `DSNU` + set タグ
`— set: image n/N, dark n/N`。表でタグは省略しない。detrend を掛けたなら
その方式と窓も同じ行に付く (下の「カットオフを必ず言う」)。

### 縞ノイズの「固定か、揺らいでいるか」

対策が違うので、これは分けないと意味がない:

- **列 FPN** — 縞が動かない。読み出し回路の列ごとのオフセット。
  平均画像 M に対して (a) の分解を掛ければ出る — 機構は既にある
  (stack の畳み込み PR #99 + (a) を Projection へ)。
- **時間的な行ノイズ (ラインノイズ)** — フレームごとに縞が変わる。電源変動など。
  **各フレームで** σ_row を出し、その**時間ばらつき**を見る。

    σ_row,fix   = 平均画像 M の行ノイズ ((a) の式で)
    σ_row,temp  = 各フレームの (I_k − M) の行ノイズ、フレーム方向に RMS
                  × √(N/(N−1))        ← I_k は M に含まれるので、この係数が要る
    (σ_col,fix / σ_col,temp も対称に同じ)

**「フレーム毎の σ_row の時間ばらつき」は誤った推定量。** 各フレームの σ_row は
毎回同じ期待値を持つので、その時間 σ は推定量のジッタ (∝ 1/√H) を測るだけで、
時間的行ノイズの振幅にならない。数値検証: 真値 6.0 DN に対して、誤った方法は
0.245、正しい方法は 5.996 を返す。

住所: どちらも役割を要しない stack の中立量なので General。
σ_row,fix は Stack Projection (= 平均画像への (a))、σ_row,temp は
**Temporal パネル**に行を足す (時間軸の解析はそこが家)。表示キーは (判断1) の
流儀で `sigma_row_fix [DN]` / `sigma_row_temp [DN]`。

## (c) 平坦な series (レベル掃引) が前提の統計

series = 条件を1つ振った stack / frame の並び。ここでの条件は **光量**。

### 既に実装済み (2026-08-07 時点)

Series Analysis パネル (PR #102、旧リニアリティパネルの一般化):
linearity fit (感度・offset・LE max)、conversion gain K (PTC)、read noise
(dark 実測 / PTC 外挿の別を列名が言う)、**SNR カーブ** (mean−dark vs σ_t、
dB 切替、ショット限界の参照線)。メンバは frame | stack 混在可 (判断record 7)、
fit に入るのは mean 統計のみ。

### この層でしか出せない、まだ無い量

| 量 | なぜ series が要るか |
|---|---|
| **DSNU と PRNU の分離** | 下記。単発の flat より遥かに堅い |
| ダイナミックレンジ | 飽和と読み出しノイズの比。飽和の定義が要る (meta) |
| 飽和容量 (full well) | K と飽和レベルから |

### 加法性と乗法性の分離 — series の本当の価値

固定パターンには**信号に比例する成分 (PRNU)** と **しない成分 (DSNU)** がある:

    σ_fpn²(μ) = DSNU² + (PRNU · μ)²        PRNU は無次元、DSNU と PRNU·μ は DN

**1つの flat レベルだけでは、この2つは分離できない。** レベルを振って上式を
フィットすれば両方が出る。しかも各点が独立の測定なので、単発より信頼できるし、
残差を見れば「本当にこのモデルか」を確認できる。

住所と役割: SetAnalyzer `{"sweep": Series(), "dark": Stack()}`
(analysis-layers.md §6)。出力は裸の `DSNU` / `PRNU` + set タグ
`— sweep: <series>, M levels`。直接推定 (b) とは**推定量が違う**ので、
タグがそのまま区別になる (同 §7)。

フィットの確定形:

- **`σ_fpn²` を `μ²` に対する線形回帰**にする (切片 = DSNU²、傾き = PRNU²)。
  厳密かつ安定で、非線形フィットを回す必要がない。**重みなし OLS (判断5)**、
  プレーン別。切片・傾きの負値は 0 クランプ + 申告 ((a) のガード規約)。
- 各レベルの `σ_fpn,ℓ²` は **(b) の補正済み推定量** (dark 減算はしない —
  減算すると切片が消えて分離にならない。加法成分ごと測るのがこのフィット)。
- **μ は dark 補正後の平均**: `μ_ℓ = mean(M_ℓ) − mean(M_dark)`。dark 役割は
  このためにも必須 — 生の μ で回すと `(μ+c)²` の交差項がモデルを壊す。
- **レベル数 M ≥ 3** (M=2 は残差ゼロの見かけ完全フィットになり、モデル検証が
  できない)。各レベルは **stack メンバ** (frame メンバは s_t が無く補正が
  引けないので fit から除外し、除外した数を言う。sum 立ちの除外則
  — analysis-layers.md §3.3 — と同じ流儀)。include フラグと値未設定の扱いは
  series の既存規約のまま。残差はレベル毎に表示する。
- **加法と乗法が無相関である仮定**の上に成り立つ。列アンプのばらつきなどは
  両者を相関させ、正しくは `DSNU² + 2ρ·DSNU·PRNU·μ + (PRNU·μ)²`。
  無相関を仮定していることを結果の note に明記する。
- **掃引は露光時間ではなく光量で行う。** 露光時間で振ると暗電流で DSNU 自体が
  動き、切片が定数でなくなってフィットが無意味になる。
- **各レベルで補正 `− C` を必ず掛けてから**フィットすること。省くと
  `μ` に比例する項 (ショットノイズ/N) が混入し、モデルが表現できないので
  **ほぼ全部が切片に吸われる**。数値検証: 真値 DSNU 3.0 に対し、補正を省くと
  **4.87 (+62%)** になる一方 PRNU は 1.200→1.240% とほぼ無傷。
  つまり症状は「DSNU だけが大きく出る」。

これは既にある series 層 (`App::Series`、`Series::members`、値と単位) に
**そのまま乗る**。新しい階層は要らない。

### EMVA 1288 を名乗るなら (未検証・要確認 — ゲート据え置き)

**この節は標準の原文に当たって確認すること。** 以下は構造としては確かだが、
版 (3.1 / 4.0) による差、推奨動作点、規定と参考の別までは確認していない。
**確認せずに画面に "EMVA 1288" と書かない** (analysis-layers.md §6 が再掲する
確定規則。フレームリニアリティの「-style を必ず付ける」と同じ線)。

記憶している形 (-style / 未検証):

    DSNU_1288 = s_y.dark / K                      [e⁻]
    PRNU_1288 = √(s²_y.50 − s²_y.dark) / (μ_y.50 − μ_y.dark)   [%]

ここから来る、本書の確定分との差:

- **本書の直接 PRNU (判断4) は画素毎減算形で、記憶している EMVA 形 (分散差)
  とは別の推定量である。** 無相関なら一致し、そうでなければ一致しない。

- **DSNU を e⁻ で出すには K が要る。** K は photon transfer = **series** から
  しか出ない。役割スキーマがそれを語る: e⁻ 系は `{"sweep": Series()}` を
  足した set でだけ実行できる (analysis-layers.md §6 の表のとおり)。
  DN 表記の DSNU に K は要らない。
- 標準準拠を名乗るには動作点 (≈50% 飽和)、L 枚平均、
  **空間周波数スペクトログラム / 高域通過版の報告**まで要る。
  「dark stack と flat stack があること」は必要条件であって十分条件ではない。
  「カットオフを必ず言う」は、この要求と同じ話。

## シェーディング除去 — 全部の土台に置く

### なぜ「機能」ではなく「段」なのか

現実に完全な平坦照明は無い。レンズのシェーディング、照明ムラ、IR カットの角度
依存が必ず乗る。そして **上の (a)(b)(c) の空間統計は全部これを拾う**。
だからシェーディング除去は個々の測定のオプションではなく、
**空間統計の前段に共通して置く1つの処理**にする。

    PlaneView → detrend(method, params) → PlaneView → 統計

### 置き場所の確定 (B5 → 判断6)

**detrend は AnalysisPreProcessor の1段である** (analysis-layers.md §5)。
それ以外の場所には置かない:

- **General パネル (Histogram / Projection / ROIs / Temporal) に detrend
  オプションは付けない。** 付ければ同じ列名で別の量が出る — §3.2 の
  「同じ表の顔で別の量を出さない」に反する。General は生の画素の中立量だけ。
- detrend 済みのデータが欲しければ、**detrend 済みの frame / stack を
  PreProcessor で生成して**から General / Specific を掛ける。生成物は一級の
  データなので何もかもそのまま効き、由来 (方式・パラメータ) は生成物の
  名前と note とレシピが運ぶ (`0e4d4ec` の不変条件、同 §5)。当面の作成経路は
  Reader (判断record 2)。
- SetAnalyzer の連鎖 (dark 減算 → detrend → 統計) の中の detrend も同じ段の
  再利用で、パラメータは結果の provenance の「数値を変えるパラメータ」欄に
  乗る (analysis-layers.md §8 が既に欄を予約している)。
- Specific `uniformity/prnu-fpn` の内蔵 9×9 は**そのまま** — 窓を自己申告する
  修飾名の解析であって、この段の代替ではない。

入口が1つなら、ローカルとピアで違う除去をしてしまう事故も構造的に防げる。

### 方式

| 方式 | 内容 | 向き |
|---|---|---|
| **多項式面フィット** | 2〜4次の面を最小二乗で当てて除算(乗法)/減算(加法) | 滑らかなレンズシェーディング |
| **ブロック中央値** | N×N ブロックの中央値で低周波面を作り除去 | 欠陥画素や絵柄に頑健 |
| **参照フラット除算** | 既知の良品フラットで割る | 照明ムラごと落とせる。**参照の役割束縛が要る** → SetAnalyzer 側の話。v1 では作らない (役割名は実装時に正典の手続きで) |
| **隣接差分** | 隣の行/列との差を取る | 行/列ノイズ専用。滑らかな傾きが厳密に消える |
| なし | 生のまま | フラット性が保証された治具のとき。**これも「カットオフの申告値」の1つ** |

### 既定 (B4 → 判断7)

- **既定は「なし (raw)」。** PRNU も σ_fpn もカットオフの関数で、**既定値が
  そのまま社内の基準値になる** (項目16-4 の警告)。自己記述的な既定は
  「何もしていない」だけである。detrend を掛けるのは明示の一手で、
  掛けた事実と窓は結果から消えない。
- **その代わり、シェーディング量は常に併記する** (下の約束4)。raw の PRNU の
  隣に `shading [%]` が立っていれば、「除去すべきだったか」は読み手が判定
  できる — 既定 OFF が黙認にならない仕掛けはこれ。
- **ON にしたときの既定方式 = 多項式2次・減算・プレーン別。** 減算型は
  約束6 (分散の一様性)、プレーン別は約束2。2次は「レンズシェーディングの
  最低次の近似」で、これより高次・別方式は全部、選んだ値が結果に付く。

### 外せない設計上の約束

1. **カットオフを必ず言う。** PRNU も σ_fpn も**空間周波数帯の関数**であって、
   「PRNU = 1.2%」だけでは再現できない。「4次面除去後」「64px ブロック除去後」
   「raw (除去なし)」まで含めて1つの測定値。**結果と一緒に必ず表示・保存する**
   (provenance の必須欄。表示側が省略できない形 = 結果構造体の必須フィールド)。
2. **プレーンごとに独立に除去する。** シェーディングはプレーンで違う
   (**色シェーディング**は実在の現象で、それ自体が測りたい量になる)。
   R の面で B を割ってはいけない。
3. **σ_t には適用しない — ただし理由を間違えないこと。** シェーディングは
   σ_t の**マップには出る** (ショットノイズが信号レベルに依存するため。§0)。
   それでも除去を掛けないのは、σ_t が測っているのが**時間方向のばらつき**で
   あって空間分布ではないから。空間的な面を引いても時間ノイズは変わらず、
   引いた分だけ意味が濁る。**detrend は空間統計にだけ掛かる段**とする。
   σ_t の空間依存を扱いたいなら、それは detrend ではなく
   **ROI を切る / レベル別に見る**という別の操作。
4. **除去した面そのものを出力にする。** シェーディング量 (中心比 %、p-p) は
   捨てるべきノイズではなく**測りたい量**。除去して終わりにしない。
5. **除去前後の両方を出す。** 「除去でどれだけ減ったか」が、そもそも除去が
   妥当だったかの判断材料になる。
6. **ノイズ統計には減算型を優先する。** 面で**除算**すると、周辺のノイズが
   1/s 倍に増幅されて**分散が場所によって変わる**。(a) の分解も
   「⟨画素毎時間分散の平均⟩」も**分散が一様であること**を前提にしているので、
   除算した画像にそのまま掛けると前提が崩れる。除算が必要なら
   (乗法性のシェーディングを扱うなら) 分散マップを s² で正規化し直す。

### 順序 (この順でしか安全に積めない)

この列がそのまま **AnalysisPreProcessor 連鎖の規範順序**である
(analysis-layers.md §5 の「順序の中身は #57 で確定」の中身)。各段の
パラメータは provenance に乗り、途中生成物を materialise したら §5 の
生成物規約 (由来を名前と note に・撮ったものの顔をしない・レシピで再計算)
が掛かる。

0. **黒レベル / OB クランプの整合**(フレーム毎に黒が動くなら、dark 減算は
   その前に壊れている。dark 減算より前に来る唯一のもの)
1a. **飽和・クリップのマスク — 必ず生値で。** dark を引いたりゲインで割った
   後では飽和レベルが一定の DN でなくなり、飽和画素が識別できなくなる。
2. **dark 減算**(加法成分を先に落とす)。**順序は入れ替えられない**:
   `y = d + s·g·μ` を先に s で割ると `d/s + g·μ` となり、**平坦だった
   オフセットにシェーディングの逆パターンが焼き付く**。
2b. **リニアリティ補正**(非線形が大きい場合)。乗法的シェーディングのモデルは
   線形性を前提にしている。v1 では作らない (段だけ予約)。
3. **シェーディング除去**(方式とパラメータを記録)
3b. **欠陥画素のマスク — detrend の後で。** 欠陥は暗基準に対する外れなので、
   シェーディングの乗った生画像に大域的な外れ値検定を掛けると**四隅が
   欠陥に見える**。面フィットと欠陥検出は相互依存なので、
   **フィット → σクリップ → 再フィット**の反復にする。
4. **統計**(プレーン別)

**この列は一本道ではなく分岐する。** σ_t は 3 の**前**(detrend しない、上の
約束3)、空間統計は 3 の**後**。1本の線に描くとこの分岐が隠れる。

**1a でマスクした瞬間、(a) の行/列の厳密な相殺が崩れる**(上述)。
4 では列ごと `H_x`・行ごと `W_y` の実サンプル数を使うこと。

v1 に存在する段は 2 (dark 減算 — reader で書ける、判断record 2) だけで、
時間方向の畳み込み (PR #99) は前処理ではなく集計側の機構としてその下流にある。
0 / 1a / 2b / 3 / 3b は本書が式と順序を確定した未実装段で、
**実装しない段を黙って飛ばすのは合法** — 飛ばした事実は「raw」等の申告値として
provenance に残る (約束1)。

- General の中立名 (`sigma_t` / `sigma_fpn` / `sigma_p/row/col` /

## 実装の進め方 (提案 — 規範ではない)

凍結中に運搬側が先に着地した (畳み込み PR #99、reader 発 set PR #101、
Series Analysis パネル PR #102)。推定量はその下流に乗るだけなので、順序は
凍結前の案から差し替える:

1. **σ_fpn 補正 `−C` を共通の蓄積器に入れる** (判断2):
   `recomputeTemporalIfNeeded` / `computeStackStats` / serve
   `runTemporalStats` の3か所は同じ形の sum/sum²/cnt を持っており、追加は
   補正項の算術のみ。合成データ (既知 FPN + 既知 σ_t) の selftest を先に
   赤で書く。**local の ddof=0 → ddof=1 (判断3) は確定済みだが実装は別 PR**
   なので、本項の補正はそれと独立に入れられる — ただし σ_t 側が揃うまで
   σ_fpn の local/server parity は緑にならない (補正項 C が s_t,i² で
   できているため)。順序は問わない、揃って初めて parity が立つ。
2. **(a) の分解を純関数として足す** (σ_p/σ_row/σ_col + H_x/W_y 対応)。
   合成データで検算する単体テストを同時に書く — 既知の σ_p のみ → 比が 0、
   既知の行オフセット → σ_row がそれを回収、W/H を変えても不変、
   マスク下で H_x/W_y 版が漏れを抑えること。Projection へ配線。
3. **縞の固定/時間分離** (σ_row,fix / σ_row,temp) を Temporal に足す。
   誤った推定量 (フレーム毎 σ_row の時間σ) との対比を selftest に残す。
4. **直接 DSNU / PRNU の SetAnalyzer** — reader 発 set (PR #101) の上で、
   1–3 の合成として。拒否 (frame 役割・dark 不在・μ≤0) の文言まで含めて。
5. **分離フィット** — series + dark 役割。レベル毎 σ_fpn² は 1 の再利用。
6. **detrend 段** (多項式面 + ブロック中央値の2方式から)。パラメータを
   結果構造体の**必須フィールド**として持たせる (表示側が省略できない)。

各段で **local と peer が同じ算術を通る**ことを parity で確認する。
